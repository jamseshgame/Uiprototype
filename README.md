# Guitar HUD VR preview

WebXR preview of the in-song guitar HUD (Today, Polish pass, Chunky 3D) for viewing in a Meta Quest headset.
Open the GitHub Pages URL for this branch in the Meta Quest Browser and press **Enter VR**.

- Trigger: next version
- Grip: re-centre

Static site only. This branch is separate from `production` and is not used by the Unity project.
